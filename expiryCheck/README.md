# 保质期检查器

一个简单实用的保质期状态检查工具，帮助您快速了解食品、药品等商品的保质期状态。

## 功能特点

- ✅ **快速查询**：输入生产日期和保质期，立即获取保质期状态
- 📊 **可视化进度条**：直观显示保质期使用进度和百分比
- 🎨 **状态分类**：三种颜色标识不同状态
  - 🟢 绿色：状态良好，在保质期内
  - 🟠 橙色：未过期但保质期已过半
  - 🔴 红色：已过期
- 💾 **常用保质期保存**：保存常用的保质期配置，下次快速选择
- 📱 **响应式设计**：支持桌面和移动设备
- 🗄️ **本地存储**：使用 IndexedDB 本地保存数据，无需服务器

## 使用方法

### 在线使用

直接在浏览器中打开 `index.html` 文件即可使用。

### 操作步骤

1. **选择常用保质期（可选）**
   - 从下拉菜单中选择已保存的保质期配置
   - 或手动输入保质期

2. **输入生产日期**
   - 点击日期选择器选择生产日期

3. **设置保质期**
   - 输入保质期数值
   - 选择单位（天或月）

4. **查询状态**
   - 点击"🔍 查询状态"按钮
   - 查看结果和进度条

5. **保存常用保质期（可选）**
   - 输入保质期后，点击"💾 保存当前保质期"
   - 下次可直接从下拉菜单选择

- **前端**：纯 HTML5 + CSS3 + JavaScript
- **数据存储**：IndexedDB
- **浏览器兼容性**：支持所有现代浏览器（Chrome、Firefox、Safari、Edge）

## 核心功能说明

### 保质期计算逻辑

- 支持以"天"或"月"为单位计算保质期
- 自动计算过期日期
- 判断保质期是否已过半
- 显示剩余时间（自动转换为月+天格式）

### 数据存储

- 使用 IndexedDB 存储常用保质期配置
- 数据保存在浏览器本地，不会上传到服务器
- 支持保存多个保质期配置，自动去重

### 进度条显示

- 根据已过天数占总保质期的比例计算进度百分比
- 进度条颜色根据状态自动变化
- 显示平滑的过渡动画效果
