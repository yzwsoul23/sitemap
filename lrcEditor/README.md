# LRC 歌词编辑器

一个功能强大的在线LRC歌词制作工具，支持音频波形可视化、实时预览和多种便捷操作。

## ✨ 功能特性

### 🎵 音频处理
- **音频上传**：支持多种音频格式（MP3、WAV、OGG等）
- **波形可视化**：实时显示音频波形，方便定位时间点
- **播放控制**：播放/暂停、进度跳转、时间显示

### 📝 歌词编辑
- **粘贴歌词**：快速粘贴文本歌词，自动分行处理
- **手动编辑**：双击歌词行可编辑文本和时间戳
- **行管理**：添加、删除、选择歌词行
- **元数据支持**：歌曲名、歌手名、专辑名、制作人信息

### ⏱️ 时间标记
- **空格键打点**：播放时按空格键自动标记当前行并跳转下一行
- **方向键导航**：上下键快速切换歌词行
- **后退功能**：按上键时音频自动后退（1-10秒可调）
- **波形点击**：点击波形图任意位置快速跳转

### 🎤 播放预览
- **歌词播放模式**：像音乐播放器一样自动滚动和高亮歌词
- **实时同步**：歌词与音频完美同步
- **问题检测**：快速发现时间标记不准确的地方

### 🎨 用户界面
- **响应式设计**：适配不同屏幕尺寸
- **暗色模式**：保护眼睛，支持主题切换
- **悬浮按钮**：左下角快速播放/暂停控制
- **平滑动画**：流畅的交互体验

## 🚀 快速开始

### 1. 上传音频
点击"🎵 上传歌曲"按钮，选择您的音频文件。

### 2. 粘贴歌词
点击"📋 粘贴歌词"按钮，在弹出的窗口中：
- 填写歌曲信息（歌曲名、歌手名、专辑名、制作人）
- 粘贴歌词文本（每行一句）
- 点击"确认"按钮

### 3. 制作时间标记
- 点击播放按钮开始播放音频
- 使用方向键选择要标记的歌词行
- 在合适的时机按空格键标记时间戳
- 系统会自动跳转到下一行

### 4. 预览和调整
- 点击"🎵 播放歌词"按钮进入预览模式
- 观察歌词与音频的同步效果
- 发现问题后可以停止播放，双击时间戳进行微调

### 5. 导出文件
点击"📤 导出LRC"按钮，下载制作好的LRC文件。

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `空格` | 播放时：标记当前行并跳转下一行<br>暂停时：播放/暂停音频 |
| `↑` | 选择上一行 + 音频后退（可设置1-10秒） |
| `↓` | 选择下一行 |
| `Enter` | 添加新歌词行 |
| `Esc` | 关闭弹窗 |
| `双击时间戳` | 编辑时间戳 |
| `双击歌词` | 编辑歌词文本 |

## 📁 文件格式

### LRC文件格式说明

```lrc
[ti:歌曲标题]
[ar:歌手名]
[al:专辑名]
[by:制作人]
[offset:0]

[00:00.00]第一句歌词
[00:05.23]第二句歌词
[00:10.45]第三句歌词
```

#### 元数据标签
- `[ti:]` - 歌曲标题（Title）
- `[ar:]` - 艺术家/歌手（Artist）
- `[al:]` - 专辑名称（Album）
- `[by:]` - 歌词制作者（By）
- `[offset:]` - 时间偏移量（毫秒）

#### 时间偏移量说明
`[offset:0]` 用于校正歌词与音频的时间偏差：
- 正值：歌词整体提前显示（如 `offset:1000` 表示提前1秒）
- 负值：歌词整体延后显示（如 `offset:-1000` 表示延后1秒）
- 0：无偏移（默认值）

## 🎯 使用场景

1. **音乐爱好者**：为自己喜欢的歌曲制作同步歌词
2. **音乐创作者**：为原创歌曲添加时间标记
3. **翻译工作者**：制作双语歌词文件
4. **KTV爱好者**：制作高质量的伴奏歌词
5. **教育工作者**：制作语言学习材料

## 💡 使用技巧

1. **快速打点**：先完整听一遍歌曲，了解节奏后再开始打点
2. **批量调整**：如果发现整体时间有偏差，可以修改offset值
3. **波形辅助**：利用波形图可以更准确地定位时间点
4. **后退设置**：根据歌曲节奏调整后退时间，提高打点效率
5. **预览检查**：制作完成后务必使用播放歌词功能检查效果

## 🔧 本地运行

1. 克隆或下载项目到本地
2. 使用HTTP服务器运行（如 `python -m http.server 8080` 或 `npx http-server`）
3. 在浏览器中访问 `http://localhost:8080`
