# 快速库存清单管理系统

一个基于Web的库存清单管理应用，支持地点和资产管理、批量操作、搜索、备份等功能。数据存储在本地浏览器中，无需服务器支持。

## 功能特性

### 基本操作
- 添加/编辑/删除数据项
- 双击复制数据内容
- 支持智能输入提示
- 键盘快捷键支持（Enter键添加/保存）

### 地点管理
- 以`@`开头的行自动标记为地点（黄底红字）
- 点击地点行可展开/折叠该地点下的所有资产
- 批量编辑地点及其所有资产
- 自动检测重复地点
- 模板资产（第一个地点）不会被导出

### 批量操作
- 批量添加数据（每行一条）
- 批量修改全部数据
- 删除全部数据（保留模板资产）
- 导出数据为TXT文件

### 搜索功能
- 实时搜索资产
- 按地点分组显示搜索结果
- 排除模板资产

### 数据备份
- 自动备份（可配置频率：每小时/每天/每周）
- 手动创建备份
- 导出备份为JSON文件
- 导入备份文件
- 恢复历史备份
- 可配置保留备份数量

### 交互优化
- 支持滑动操作（左滑编辑、右滑删除）
- 一键折叠/展开所有地点
- 快速滚动到列表底部
- 响应式设计，支持移动端

## 技术栈

- **HTML5**: 页面结构
- **CSS3**: 样式和动画

- **IndexedDB**: 本地数据存储
- **localStorage**: 备份和设置存储

## 快速开始

### 安装

1. 克隆或下载项目文件
2. 使用浏览器打开 `index.html` 文件

### 使用说明

#### 添加数据
1. 在输入框中输入内容
2. 按下回车键或点击添加按钮
3. 数据将自动保存并显示在列表中

#### 添加地点
1. 在输入框中输入以`@`开头的地点名称，例如：`@办公室`
2. 按下回车键添加
3. 地点行将显示为黄底红字

#### 添加资产
1. 在地点下方添加资产项
2. 资产会自动编号（1. 2. 3. ...）
3. 点击地点行可折叠/展开资产列表

#### 编辑数据
- 方法1：向左滑动数据行
- 方法2：双击数据行复制内容

#### 删除数据
- 方法1：向右滑动数据行
- 方法2：点击地点行右侧的✏️按钮批量编辑

#### 搜索资产
1. 点击右下角的🔍按钮
2. 输入搜索关键词
3. 查看按地点分组的搜索结果

#### 数据备份
1. 点击左下角的💾按钮
2. 选择备份操作（立即备份/恢复/导出/导入）
3. 配置自动备份设置

## 数据存储

### IndexedDB
- 主要数据存储在浏览器的IndexedDB中
- 数据库名称：`ItemsDB`
- 对象存储：`items`

### localStorage
- 备份数据存储在localStorage中
- 备份设置存储在localStorage中

## 浏览器兼容性

- Chrome/Edge: 完全支持
- Firefox: 完全支持
- Safari: 完全支持
- IE: 不支持（需要ES6+支持）

## 注意事项

1. **数据安全**: 数据存储在本地浏览器中，清除浏览器数据会导致信息丢失
2. **定期备份**: 建议定期导出备份文件
3. **模板资产**: 第一个地点`@模板资产`不会被导出
4. **地点重复**: 相同地点名称不允许重复添加

- 大数据量时自动启用分页或分批渲染
- 定期清理内存
- 使用DocumentFragment减少DOM操作
